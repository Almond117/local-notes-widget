# 本地便签

一个仿照参考图制作的 Windows 离线桌面便签。便签数据、窗口位置和置顶状态均保存在本机。

## 使用

安装依赖后启动桌面应用：

```powershell
npm install
npm start
```

生成免安装的 Windows 可执行程序：

```powershell
npm run pack
```

生成结果位于 `release` 文件夹。也可以直接双击 `index.html` 预览网页模式，但窗口控制和导入/导出只在桌面版中可用。

## 功能

- 彩色分类筛选与自定义分类
- 新增、编辑、删除和更换分类
- 完成、恢复以及完成时间记录
- 已完成列表折叠
- 浏览器本地持久化，刷新或重新打开后数据仍保留
- 独立本地数据文件与 JSON 备份导入/导出
- 无外围框窗口、四边/四角自由缩放、置顶、最小化与窗口位置和尺寸记忆
- 搜索、新增、置顶、皮肤和窗口操作合并在彩色分类标题栏内
- 按住彩色标题栏的空白区域即可拖动整个便签窗口
- 便签内容只保存在本机数据目录，不会写进安装包
- 分类标签和便签面板使用相同颜色，预设颜色扩展到 24 种
- 双击便签文字进入行内编辑，Enter 保存、Esc 取消
- 搜索便签，分类切换时清单跟随标签颜色变化
- 16 种预设皮肤、自定义颜色、黑色主题和 25%–100% 透明度调节
- 全分类实时搜索、关键词高亮、`Ctrl+F` 搜索与 `Ctrl+N` 新增快捷键
- Windows 到点通知与便签提醒时间
- 系统托盘、隐藏到托盘和可选开机启动
- 分类改名、换色、排序和安全删除
- 回收站、永久删除以及 `Ctrl+Z` 撤销误删
- 窗口外层背景完全透明，桌面壁纸可直接透出
- 高层级图钉置顶，状态自动记忆
- 手机和桌面窄窗口自适应
